# Horno Abraham · web de muestra

Propuesta de web para **Horno Abraham**, horno y pastelería de barrio en Jesús (València): C/ de Tomás de Villarroya, 11 · tel. 633 61 53 25 · [@hornoabraham_](https://www.instagram.com/hornoabraham_/).

**Web online:** https://nocodya-hue.github.io/horno-abraham/

- Web estática: HTML, CSS y JS, con GSAP y Lenis para las animaciones. Sin cookies ni analítica.
- Horario real con indicador de «abierto ahora» y lista de panes por encargo copiada de la pared del horno.
- Encargos por WhatsApp.
- Reseñas reales de Google, recortadas y con el nombre abreviado.

**Sobre las imágenes**
- Fachada, pared y vitrinas: fotos reales de la ficha de Google Maps.
- Tira de Instagram: miniaturas de sus publicaciones.
- Producto: recreado con IA a partir de sus propias fotos (croissants, tartas, pan, muffins). Las empanadillas y los salados son ilustrativos.

**Pendiente de confirmar con el negocio:** que el teléfono tenga WhatsApp, razón social y NIF para el aviso legal, y el dominio definitivo.
